# Shell Patterns Bundle

This crate stages bevydcc host and UI composition patterns that map well to GreebleFS shell work.

Primary value:

- data-driven panel and surface composition
- host routing patterns for command and subsystem orchestration
- runtime diagnostics patterns for editor-grade shells
- asset-browser reference material for UX ideas and thumbnail cache behavior

Caveat:

- `asset_browser.rs` is useful reference material, but it is not a scalability model for a large virtualized explorer. Treat it as pattern source, not as the target rendering architecture.

The copied upstream files live under `upstream/` with original relative paths preserved.
