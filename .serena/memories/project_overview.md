GreebleFS is a Tauri desktop workbench with a flagship explorer and broader shell surfaces including terminal, plugins, screenshots, settings, mobile share, notes, and storage tooling. Core stack: React 19 + TypeScript + Vite on the frontend, Zustand for state, Tauri 2 + Rust for native/Desktop truth, Specta-generated bindings for the Rust/TS bridge, and some Python-sidecar/PyO3 support for specialized runtime work. The repo shape to preserve is Rust owns truth, Specta owns typed contracts, TS runtime/store layers orchestrate, and React renders. Important top-level folders: `src/` frontend shell/runtime/store/config, `src-tauri/` native host/commands, `crates/` shared contracts and vendored engine substrate, runtime-authored roots like `themes/`, `plugins/`, `shaders/`, `animations/`, `wallpapers/`, `notes/`.
