# Kain Cargo FFI Lane

Cargo FFI is the Kain bridge for Rust crates and crate-backed tooling. Keep this lane for plugin/runtime experiments that should use the Rust ecosystem without immediately becoming GreebleFS host code.

The first declared consumer is `usr/plugins-kain/kain-workbench-smoke`, which carries a tiny crate under `plugin.runtime/cargo/` as the contract proof.
