# AppleCommand (Mobile OverlayTerm Host)

AppleCommand is a **mobile-first LAN host** for accessing OverlayTerm-like shell features from iPhone/Safari.

## What this scaffold gives you

- Runs a standalone mobile web app on **`0.0.0.0:3000`** (LAN accessible)
- Token-protected WebSocket shell bridge
- Touch-first UI for command execution and live output
- Works independently from the Tauri desktop window

## Quick start

```bash
cd M:/OverlayTerm/AppleCommand
npm install
npm start
```

Server prints LAN URLs like:

- `http://192.168.x.x:3000?token=...`

Open that URL on your iPhone Safari while on the same Wi-Fi/network.

## Security

- Access requires token (`APPLE_COMMAND_TOKEN` env var or autogenerated startup token)
- Intended for trusted local network use
- Do **not** expose port 3000 to the public internet

## Environment variables

- `APPLE_COMMAND_HOST` (default `0.0.0.0`)
- `APPLE_COMMAND_PORT` (default `3000`)
- `APPLE_COMMAND_TOKEN` (default random startup token)
- `APPLE_COMMAND_SHELL` (default `pwsh.exe`)
- `APPLE_COMMAND_CWD` (default current dir)
